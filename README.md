# vantuzfed.github.io — v2

Редизайн личного сайта в духе Windows XP: тот же стиль, но на современном стеке
и с адаптацией под мобильные устройства.

## Что изменилось по сравнению со старой версией

- **Стек**: Vite + TypeScript вместо голых `<script>`-тегов и jQuery/jQuery UI.
  Перетаскивание окон реализовано на Pointer Events (`src/drag.ts`), без
  зависимости от jQuery UI.
- **xp.css и Webamp** подключены как npm-пакеты и собираются локально, а не
  тянутся с unpkg/CDN в рантайме.
- **Мобильная версия** — не отдельный поддомен `m.*` (который в старом
  репозитории не существовал физически), а часть той же сборки: на узких
  экранах рабочий стол превращается в сетку иконок, а каждое окно открывается
  как полноэкранное "приложение" с кнопкой «Назад» в заголовке.
- **Меню Пуск** теперь реально работает: из него можно заново открыть любое
  закрытое или свёрнутое окно (в старой версии закрытые окна нельзя было
  вернуть, кроме полного сброса кнопкой Reset).
- **Winamp и Three.js подключены лениво** (`dynamic import`), поэтому они не
  утяжеляют первую загрузку страницы.
- Собственный чекер Minecraft-сервера, changelog, галерея, cube-игрушка и
  3D-демо на three.js перенесены как есть, но переписаны без jQuery.
- BSOD-страница 404 сохранена (`public/404.html`), просто без jQuery.

## Структура проекта

```
├── index.html         # входная точка (рабочий стол / мобильный домашний экран)
├── gallery.html        # галерея
├── cube.html            # игрушка с кубом
├── threed.html          # демо three.js
├── src/
│   ├── main.ts          # инициализация рабочего стола
│   ├── manager.ts        # окна, панель задач, меню Пуск, мобильный режим
│   ├── apps.ts            # реестр "приложений" (контент окон)
│   ├── drag.ts             # перетаскивание окон (Pointer Events)
│   ├── features/            # чекер minecraft, changelog, winamp
│   └── styles/                # CSS (base, windows, page, cube)
├── public/
│   ├── img/, dos_font.ttf, favicon.ico, data/changelog.txt
│   ├── 404.html             # BSOD-заглушка
│   └── CNAME                 # домен vantuzfed.ru (поменяйте/удалите при необходимости)
└── .github/workflows/deploy.yml  # автодеплой на GitHub Pages при пуше в main
```

## Разработка

```bash
npm install
npm run dev       # локальный сервер с горячей перезагрузкой
npm run build      # сборка в dist/
npm run preview     # проверка собранной версии
```

## Деплой

Репозиторий настроен под GitHub Pages:

1. В настройках репозитория → **Pages** → Source: **GitHub Actions**.
2. При каждом пуше в `main` workflow `deploy.yml` соберёт проект и опубликует
   `dist/`.
3. Файл `public/CNAME` содержит `vantuzfed.ru` — измените или удалите его,
   если домен нужен другой (или вообще не нужен — тогда сайт будет доступен
   на `<user>.github.io`).
